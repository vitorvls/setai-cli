# Challenge Solution

Critically challenge a proposed solution for SetAI.

## Context

- `.cursor/context/architecture.md`
- `.cursor/context/project-goals.md`
- `.cursor/context/known-issues.md`
- `.cursor/rules/business-rules.md`

## Instructions

1. Restate the proposal briefly.
2. Attack weak assumptions (especially web/API defaults, unverified deps, CI myths).
3. Check fit with deterministic core + optional `--beta`.
4. Propose a simpler alternative if possible.
5. List evidence needed before accepting the approach.

## Constraints

- Be constructive and specific.
- Prefer repository evidence over generic best practices.

## Output

Challenges, risks, alternative, evidence checklist.
